# Air Amanah — Water Delivery Management Application

Air Amanah is an Android-based mobile application designed to support the daily operations of a water gallon delivery business.

Developed using Flutter and Dart, the application brings essential business management activities into a single mobile interface, helping organize orders, customer records, inventory, payments, and business reports.

## Key Features

- **Business Dashboard** — Displays sales, payments, outstanding balances, and gallon stock summaries.
- **Order Management** — Supports order creation and order status tracking.
- **Delivery Management** — Records delivery confirmation and gallon returns.
- **Customer Management** — Organizes customer information.
- **Inventory Management** — Supports product and gallon stock tracking.
- **Payment Tracking** — Records payments and monitors outstanding customer balances.
- **Business Reports** — Presents financial summaries and sales comparisons.
- **Bluetooth Thermal Printing** — Integrates a Bluetooth thermal printer for order receipt printing.

## Technology Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **Local Database:** SQLite
- **Hardware Integration:** Bluetooth Thermal Printer
- **Printing Protocol:** ESC/POS
